Scope

This policy covers the Academy Sentiment Research Pilot, an independent, non-commercial undergraduate thesis prototype focused only on public YouTube comments. The site itself does not create user accounts, set analytics cookies, accept uploads, or request Google login.

Data accessed through official APIs

  • Public YouTube video metadata, comments, and replies returned by the YouTube Data API.
  • Technical provenance such as query label, capture time, source type, page cursor status, and code version.

The research does not seek private messages, email addresses, protected traits, precise location, advertising identifiers, or non-public account data. OAuth access to a visitor's Google account is not required.

Purpose and legal basis

Data is used only to test collection feasibility, select relevant public texts, compare two sentiment-classification methods, evaluate model error, and document reproducibility. The project does not make decisions about individuals, sell data, serve advertisements, or build user profiles.

Minimization and security

Account names and user IDs are removed from the analytical dataset. Access tokens and API keys are kept outside version control. Raw data is stored locally with access limited to the researcher. Publications use aggregate results or paraphrased examples when a verbatim quote could be searchable.

YouTube Data API Services

The project uses YouTube API Services and is therefore also governed by the YouTube Terms of Service and Google Privacy Policy. YouTube video titles, creator names, descriptions, and comment text are refreshed or deleted within 30 days. Derived sentiment metrics are created or retained beyond that period only if Google accepts the applicable Analytics & Reporting amendment; accepted derived metrics may be retained for no more than 36 months.

Sharing

Raw YouTube API data is not sold, licensed, or published as a downloadable dataset. Aggregate results may appear in an academic proposal, thesis, presentation, or repository. Service providers are not given API credentials or raw datasets.

Deletion requests

A public content author may request removal of a comment from the research dataset by following the data deletion instructions. The researcher will verify the public YouTube URL or content identifier and remove the matching record from active research files and the next refresh.

Changes and contact

Material changes will be dated on this page. Questions or deletion requests can be sent to richardcen05@gmail.com.
